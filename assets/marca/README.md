# Marca Mural 17

O símbolo é um recado preso no mural: papel vermelho, tachinha, canto dobrado e o 17, o DDD da região. O nome "Mural" usa Source Serif 4 (peso 800); o 17 usa IBM Plex Sans (700). Nos SVGs o texto já está convertido em curvas, então eles não dependem das fontes instaladas.

| Arquivo | Uso |
|---|---|
| `mural17-logo.svg` | Logo principal, fundo claro (cabeçalho do site) |
| `mural17-logo-negativo.svg` | Fundo escuro (rodapé, posts) |
| `mural17-logo-mono.svg` | Uma cor (impresso, carimbo) |
| `mural17-simbolo.svg` | Símbolo sozinho (avatar, selo) |
| `mural17-favicon.svg` | Favicon, sem a tachinha, para tamanhos pequenos |
| `mural17-icone-512.png` | Ícone do site (Personalizar › Identidade do site) |
| `mural17-icone-180.png` | Ícone do iPhone |
| `mural17-compartilhamento.png` | Imagem padrão de compartilhamento, 1200 × 630 |
